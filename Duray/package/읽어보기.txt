두레이 자동 출퇴근 2.1.3 - 설치 및 사용 안내
========================================

설치 / 업데이트
  1. 이 폴더의 설치.bat을 실행합니다.
  2. 필요한 버전의 Chromium이 없으면 다운로드합니다.
  3. 바탕화면의 두레이 자동출근을 실행합니다.
  기존 계정·출근시간·달력 설정과 Windows 자격 증명은 유지됩니다.
  기존 EXE·설정·예약은 %LOCALAPPDATA%\DoorayCheckin\backups에 백업합니다.
  업데이트 중 오류가 발생하면 기존 버전과 예약을 복원합니다.
  기존에 켜져 있던 예약은 새 달력 기반 예약으로 전환합니다.
  설치 실패 안내가 나오면 앱에서 상태를 확인하고 자동 예약을 다시 켜세요.

처음 사용하기
  1. 연결 · 설정: 회사 두레이 주소, 로그인 ID, 비밀번호 입력 후 저장하고 연결 확인을 누릅니다.
  2. 시간 · 예약: 자동 출근/퇴근을 각각 선택하고 시·분·초를 드롭다운에서 선택합니다.
     HH:MM 또는 HH:MM:SS, 랜덤은 이전/이후 0~720분을 각각 지정합니다.
  3. 근무 달력: 날짜를 선택해 휴가, 반차, 휴무, 대체근무일을 지정합니다.
     출근/퇴근을 각각 켜거나 끄고 해당 날짜의 시각을 별도로 저장할 수 있습니다.
  4. 출근 점검 (기록 없음) / 퇴근 점검 (기록 없음)로 버튼 인식을 확인합니다. 테스트는 클릭하지 않습니다.
  5. 하단의 저장하고 자동 예약 시작을 누르고 '자동 예약 실행 중'을 확인합니다.
     설정만 저장하면 예약은 켜지지 않습니다.
     앞뒤 범위를 쓰려면 '랜덤 범위'를 선택하세요. 고정 시각에는 적용되지 않습니다.

앱에서 업데이트하기 (2.1.3 이상)
  연결 · 설정 > 업데이트 확인 > 다운로드 및 설치를 누릅니다.
  공식 GitHub 파일을 다운로드하고 SHA-256을 검증한 뒤 기존 설정을 유지하여 설치합니다.
  설치 과정에서 앱이 종료된 뒤 새 버전으로 다시 열립니다.
  실패 기록: %LOCALAPPDATA%\DoorayCheckin\updates 아래 install.log

두레이 휴가 / 반차 연동
  연결 · 설정에서 본인 월별 근태 경로를 확인하고 이번 달 근태 가져오기를 실행합니다.
  기본 경로: /work-schedule/user/register-month
  가져온 휴가와 반차를 확인한 후 자동 반영 체크박스를 켜고 저장하세요.
  자동 예약이 켜져 있으면 설정한 간격으로 갱신하고, 실행 직전에도 근태를 확인합니다.
  조회 실패나 미확인 근태는 자동 처리하지 않으며 실행 기록에 원인을 표시합니다.
  연동은 현재 월을 대상으로 합니다. 다른 달은 수동 달력 설정이 가능합니다.
  임의의 회사 휴일이나 신규 대체휴일은 달력에 직접 등록할 수 있습니다.

반차 처리
  반차에도 출근은 원래 지정한 시각과 랜덤 범위를 유지합니다.
  시간 · 예약에서 오전 반차 / 오후 반차의 퇴근 시각을 각각 지정하세요.
  두레이 근태 유형에 따라 해당 퇴근 시각을 적용합니다.
  기본 시각 유지 또는 반차일 자동 퇴근만 OFF로 바꿀 수도 있습니다.
  시간차/반반차처럼 시간대를 확정할 수 없는 휴가는 자동 처리를 끕니다.
  필요한 경우 해당 날짜에서 직접 시각을 지정하고 켜세요.

설정 우선순위
  전체 출근/퇴근 사용 OFF > 날짜별 출근/퇴근 ON/OFF > 날짜 유형 수동 설정
  > 기존 제외 날짜 > 두레이 근태 > 근무 요일/한국 공휴일 > 기본 시각.
  날짜별 ON은 휴일과 휴가를 무시하지만 전체 출근/퇴근 OFF를 켜지는 않습니다.
  날짜별 시각만 입력하면 OFF인 날짜가 켜지지는 않습니다.

예약과 수동 실행
  창을 닫아도 Windows 예약은 유지됩니다. PC가 켜져 있고 로그인되어 있어야 합니다.
  예약 시각부터 지연 허용 시간(기본 15분) 내에서만 실행합니다.
  초 단위 시각을 입력할 수 있으며 실제 처리는 PC/네트워크 상태에 따라 지연됩니다.
  랜덤 시각은 날짜마다 정해지고 재시작해도 같은 날에는 유지됩니다.
  자정을 넘는 야간 근무는 지원하지 않습니다.
  퇴근은 당일 출근 기록이 두레이 화면에서 확인될 때만 처리합니다.
  지금 출근/퇴근은 확인창을 거쳐 실제 처리하며 날짜별 OFF를 무시합니다.
  출근과 퇴근은 각각 같은 날 중복 처리하지 않습니다.

문제 해결 / 제거
  실행 기록에서 로그와 스크린샷 폴더를 열 수 있습니다.
  로그인 결과와 오류별 해결 방법은 연결 · 설정의 계정 입력란 아래에 표시됩니다.
  회사 주소에는 https://회사.dooray.com까지만, /home은 페이지 경로에 입력하세요.
  비밀번호를 비워두면 현재 ID에 저장된 값을 사용합니다. ID 변경 시 비밀번호도 다시 입력하세요.
  SSO·OTP는 브라우저에서 직접 로그인 버튼을 누른 뒤 직접 인증을 완료하세요.
  최대 3분 기다리며 앱에서 취소할 수 있습니다. 일반 Chrome과 앱의 로그인 세션은 별개입니다.
  비밀번호 오류·잠금·추가 인증 등이 감지되면 자동 재시도를 멈춥니다.
  수정 후 저장하고 연결 확인으로 다시 확인하세요. 연결 확인은 실제 출퇴근을 하지 않습니다.
  로그인 성공 / 근태 조회 실패가 표시되면 본인 월별 근태 경로와 조회 권한을 확인하세요.
  2.1.1은 계정별 세션을 분리하므로 업데이트 후 첫 연결에서 다시 로그인할 수 있습니다.
  앱에서 자동 예약 끄기 후 바로가기를 삭제하면 예약을 중지할 수 있습니다.
  완전 삭제 시 %LOCALAPPDATA%\DoorayCheckin 폴더와 Windows 자격 증명 관리자의
  dooray-checkin 항목을 삭제하세요. 먼저 필요한 설정/로그를 백업하세요.

[2.1 개선 사항]
  - 두레이 스타일의 밝은 캘린더와 파란색 강조 디자인.
  - 출근/퇴근/반차/날짜별 시각을 시·분·초 드롭다운으로 선택.
  - 앱을 열면 저장된 계정의 이번 달 본인 근태를 가져옵니다.
  - 자동 예약 반영이 꺼져 있어도 가져온 연차·반차는 달력에 표시합니다.
  - 날짜를 클릭하면 오른쪽에서 근태와 예약 시각을 확인·수정합니다.
  - 날짜별 시간은 기본 시간 사용으로 쉽게 되돌릴 수 있습니다.
  - 실제 예약에도 적용하려면 달력 아래 근태 반영 체크 후 설정 저장.
  - 현재 월 근태를 조회합니다. 다른 달은 날짜별로 직접 설정할 수 있습니다.

[2.1.3 수정 사항]
  실패 알림·재시도 대기 중 잠금을 해제하고 작업이 겹치면 순서대로 기다립니다.
  선택 가능한 90일 비밀번호 변경 안내는 다음에 변경하기로 계속 로그인합니다.
  필수 변경은 중단하며 2.1.1의 잘못된 만료 차단은 다시 확인합니다.
  점검은 실제 기록을 생성하지 않습니다. 지금 출근 / 지금 퇴근은 확인 후 실제 처리합니다.
