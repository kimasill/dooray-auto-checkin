두레이 예약 실패 진단 도구

1. 예약이 실패한 PC에서, 두레이 앱을 사용한 Windows 계정으로 실행합니다.
2. ZIP을 압축 해제한 다음 '진단로그수집.bat'을 더블클릭합니다.
3. 바탕화면에 만들어진 Dooray-diagnostics-날짜-시간-식별자.zip을 전달합니다.
4. 실패 날짜와 기대한 출근/퇴근 시각, 당시 PC 절전/종료 여부를 함께 알려주세요.

관리자 권한이나 새 버전 설치는 필요하지 않습니다.
실행 중인 앱·Windows 예약·설정·출퇴근 기록을 변경하지 않습니다.
이 도구는 자동으로 자료를 전송하지 않습니다.

수집: 예약 설정, 최근 로그, 처리 상태, 앱 버전, Windows 예약과 절전/부팅 이벤트.
제외: 비밀번호 저장소, 계정 ID/회사 URL, 로그인 쿠키/프로필, 스크린샷,
      원본 config.json, 달력의 전체 휴가 내역, 날짜별 메모.
일부 Windows 기록을 읽지 못해도 나머지 자료를 ZIP으로 만듭니다.

도구 실행이 불가능하면 Win + R에서 아래 경로를 열어 checkin.log를 전달하세요.
%LOCALAPPDATA%\DoorayCheckin\logs
원본 로그에는 계정/주소가 남을 수 있으므로 가능하면 진단 도구를 사용하세요.
