# 두레이 자동 출퇴근 2.1.6

Windows 데스크톱 프로그램입니다. 대시보드, 근무 달력, 시간·예약, 연결·설정, 실행 기록 화면에서 자동 출퇴근을 관리합니다.

## 사용

배포 폴더의 `설치.bat`을 실행합니다. 기존 `%LOCALAPPDATA%\DoorayCheckin` 설정과 Windows 자격 증명을 보존하며, 필요한 Chromium 버전을 확인합니다. 기존에 켜져 있던 예약은 달력 기반 예약으로 전환하고 꺼져 있던 예약은 그대로 유지합니다. 기존 출근 시각과 계정 설정 파일은 변경하지 않습니다. 자동 퇴근은 처음에는 꺼져 있습니다.

업데이트 전에 기존 실행 파일·설정·예약을 `%LOCALAPPDATA%\DoorayCheckin\backups`에 백업하며, 업데이트에 실패하면 기존 실행 파일·설정·예약을 복원합니다. 새 버전에 필요한 Chromium은 기존 프로그램을 중지하기 전에 준비합니다.

1. **연결 · 설정**에서 회사 주소·로그인 ID·비밀번호를 입력하고 **저장하고 연결 확인**을 누릅니다.
2. **시간 · 예약**에서 출근/퇴근을 각각 켜고 시·분·초 드롭다운과 근무 요일을 설정합니다.
3. **근무 달력**에서 특정 날짜의 휴가·휴무·반차·대체근무를 설정합니다.
4. **출근 점검 (기록 없음) / 퇴근 점검 (기록 없음)**로 화면 인식을 확인합니다. 실제 출퇴근 버튼은 클릭하지 않습니다.
5. **저장하고 자동 예약 시작**을 누른 뒤 **자동 예약 실행 중**을 확인합니다. ‘설정만 저장’은 예약을 켜지 않습니다.

고정 모드에서는 랜덤 범위가 적용되지 않으며 입력란도 비활성화됩니다. 앞뒤 범위를 적용하려면 **랜덤 범위**를 선택하세요. 대시보드는 범위 안에서 선택된 오늘의 실제 실행 시각을 표시합니다.

2.1.3부터 **연결 · 설정 → 업데이트 확인 → 다운로드 및 설치**로 최신 GitHub 배포본을 설치할 수 있습니다. HTTPS로 받은 배포 목록과 GitHub SHA-256을 대조하고, 검증된 설치 파일만 실행합니다. 업데이트 중 설치 기록은 `%LOCALAPPDATA%\DoorayCheckin\updates` 안의 `install.log`에서 확인할 수 있습니다.

연결 결과와 해결 방법은 계정 입력란 아래에 표시됩니다. SSO·OTP는 **브라우저에서 직접 로그인**으로 직접 완료하세요. 로그인 성공과 근태 조회 성공은 구분하며, 연결 확인은 출퇴근 기록을 변경하지 않습니다. 자세한 오류별 조치는 [연결 문제 해결](../README.md#연결이-안-될-때)을 참고하세요.

## 달력과 시간 규칙

- 날짜별로 출근/퇴근을 각각 **기본 규칙 / 켜기 / 끄기**로 설정합니다.
- 날짜 유형은 자동 판정, 근무일, 휴무/대체휴일, 종일 휴가, 오전 반차, 오후 반차입니다.
- 날짜별 시각은 고정 시각으로 적용합니다. **기본 시간 사용**을 체크하면 기본 시간 규칙을 사용합니다.
- 출근과 퇴근 시각은 `HH:MM` 또는 `HH:MM:SS`를 지원합니다.
- 랜덤 범위는 기준 시각 **이전/이후 각각 0~720분 + 0~59초**입니다. 범위의 양 끝을 포함하여 1초 단위로 날짜마다 시각을 정하고 같은 날짜에는 재시작해도 유지합니다. 자정을 넘는 범위는 당일 안으로 제한합니다.
- **반차에도 출근은 원래 설정한 시각과 랜덤 범위를 유지합니다.** 오전 반차/오후 반차의 퇴근 시각을 각각 지정하면 근태 유형에 맞춰 적용합니다. 기본 시각 유지 또는 반차일 자동 퇴근 OFF도 선택할 수 있습니다.
- 날짜별 ‘켜기’는 휴가·휴일보다 우선합니다. 전체 출근/퇴근 사용 OFF는 날짜별 ON보다 우선합니다.
- 일반 근무일은 요일 설정과 한국 공휴일/대체공휴일에 따라 판정합니다. 회사 휴일과 새로 정해진 대체휴일은 직접 지정할 수 있습니다.

우선순위: 전체 사용 OFF → 날짜별 ON/OFF → 수동 날짜 유형 → 기존 제외 날짜 → 두레이 근태 → 근무 요일/공휴일 → 기본 시각. 날짜별 시각만 입력해도 OFF인 날짜가 자동으로 켜지지는 않습니다.

## 두레이 근태 연동

본인 월별 근태 경로의 기본값은 `/work-schedule/user/register-month`입니다. 앱 시작 시 저장된 계정의 이번 달 근태를 가져옵니다. 근무 달력 화면을 열어 둔 동안 설정된 갱신 간격으로 새 내용을 가져오며, 실패 시에는 최소 5분 뒤 다시 시도합니다. **이번 달 근태 가져오기**로 즉시 새로 고칠 수도 있습니다.

가져온 연차·휴가, 오전 반차, 오후 반차는 자동 예약 반영 여부와 관계없이 캘린더에 표시됩니다. 연차는 보라색, 오전 반차는 주황색, 오후 반차는 초록색으로 표시하며, 날짜를 선택하면 오른쪽에서 두레이 근태 원문·기간과 실제 예약 시각을 확인합니다. **두레이 근태를 자동 예약에도 반영**을 체크하고 설정을 저장하면 휴가/반차가 자동 출퇴근 규칙에 적용됩니다. 기존 설정은 업데이트 시 바꾸지 않습니다.

달력은 일요일부터 시작하며 오늘은 파란 원, 선택한 날짜는 파란 테두리, 날짜별 수동 설정은 파란 점으로 표시합니다. 방향키로 날짜를 이동할 수 있습니다. 두 시각을 한 줄로 표시할 때는 출근 · 퇴근 순서입니다. 화면은 [Dooray 공식 캘린더](https://dooray.com/main/service/calendar/)의 밝은 바탕, 파란색 강조, 월간 일정 구성을 참고한 개인 자동화 도구입니다.

로그인한 브라우저가 개인 근태 화면을 표시할 때 사용하는 동일 사이트의 `GET /wapi/work-schedule/v1/off-duties` 응답을 읽습니다. 사이트의 정상 조회 요청을 관찰하며 별도 쓰기 API를 호출하지 않습니다. 조회 범위가 월의 첫날~말일이고, 성공 응답과 전체 건수가 확인된 경우만 사용합니다. 휴가가 0건인 정상 응답과 조회 실패를 구분합니다. 다른 직원/팀 조회 파라미터가 포함된 응답은 사용하지 않습니다.

- 연차/휴가, 오전·오후 반차와 여러 날짜의 휴가를 반영합니다.
- 자동 예약이 켜져 있으면 설정한 간격으로 갱신하고, 실제 자동 실행 직전에도 근태를 다시 읽습니다.
- 실패하거나 근태 종류를 확정할 수 없으면 해당 자동 처리를 보류합니다. 수동 날짜 설정은 우선합니다.
- 현재 월을 동기화합니다. 다른 달은 수동 달력 설정이 가능합니다.
- 회사별 화면 구조 차이에 대비해 날짜가 명시된 월별 DOM 읽기도 지원합니다. 필요한 경우 설정의 달력 영역 CSS 선택자를 지정합니다. 임의의 전체 페이지 휴가 문구만으로 날짜를 추측하지 않습니다.
- 앱은 두레이 근태 원본을 수정하지 않습니다.


## 예약 동작과 보호 장치

Windows `DoorayCheckin` 작업은 `--watch` 모드로 실행됩니다. 하나의 백그라운드 프로세스가 약 2초 간격으로 설정과 날짜를 확인합니다. 브라우저는 근태 갱신 또는 실제 처리 시에만 실행합니다. 로그인 시 시작하고 5분 간격의 재시작 트리거가 중단된 프로세스를 복구합니다. 창을 닫아도 유지됩니다.

- PC가 켜져 있고 Windows에 로그인되어 있어야 합니다. 로그아웃/전원 꺼짐 상태에서는 실행되지 않습니다.
- 한국 시간으로 판정합니다. 지연 허용 시간은 기본 15분이며, 0분은 시각부터 5초 이내 시작만 허용합니다. 브라우저·네트워크에 따른 처리 지연은 발생할 수 있습니다.
- 당일 근무만 지원합니다. 출근과 퇴근 범위가 겹치는 설정은 저장하지 않습니다.
- 출근/퇴근의 성공 날짜를 별도로 기록하며 수동 실행도 같은 날 중복 처리하지 않습니다.
- 퇴근은 두레이 화면에 오늘의 출근 시각이 확인되어야 실행합니다.
- 반대 동작의 버튼 문구는 거부합니다. 클릭 후 해당 칸에 시각이 기록되어야 성공입니다. 버튼 비활성만으로 성공으로 기록하지 않습니다.
- 프로세스 잠금으로 예약/수동 작업/동기화가 같은 브라우저 프로필을 동시에 사용하는 것을 막습니다.
- 설정과 상태 파일은 원자적으로 교체하며, 실행 중 설정이 바뀌면 클릭 직전에 다시 검사합니다.

## 주요 설정

| 키 | 의미 |
|---|---|
| `checkin_enabled`, `checkout_enabled` | 출근/퇴근 사용 |
| `checkin_time`, `checkout_time` | 기준 시각 |
| `time_mode`, `checkout_time_mode` | `fixed` / `random` |
| `random_before_minutes`, `random_after_minutes` | 출근 랜덤 이전/이후 분 |
| `checkout_random_before_minutes`, `checkout_random_after_minutes` | 퇴근 랜덤 이전/이후 분 |
| `random_before_seconds`, `random_after_seconds` | 출근 랜덤 범위의 추가 초 (0~59) |
| `checkout_random_before_seconds`, `checkout_random_after_seconds` | 퇴근 랜덤 범위의 추가 초 (0~59) |
| `workdays` | 월요일=0 ~ 일요일=6 |
| `date_overrides` | 날짜별 유형, ON/OFF, 시각, 메모 |
| `half_day_policy` | `checkout_time` / `keep_time` / `skip_checkout` |
| `am_half_checkout_time`, `pm_half_checkout_time` | 오전/오후 반차 퇴근 시각 |
| `late_grace_minutes` | 예약 시작 지연 허용 분 |
| `dooray_sync_enabled` | 근태 자동 반영 |
| `sync_interval_minutes` | 근태 갱신 간격 (5~1440분) |

이전 `random_window_minutes`, `skip_dates`, 계정 및 버튼 선택자 설정을 읽을 수 있습니다. 이전 대칭 랜덤 폭은 이전/이후 분 값으로 변환합니다. 새 초 설정은 기본 0이므로 업데이트만으로 기존 범위나 오늘 선택 시각은 달라지지 않습니다. 분 단위 범위도 실행 시각은 초 단위로 추첨합니다. 비밀번호는 JSON에 저장하지 않습니다.

## 개발 / 검사

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r Duray/requirements.txt pyinstaller
.venv/Scripts/python.exe -m playwright install chromium
.venv/Scripts/python.exe Duray/dooray_gui.py
.venv/Scripts/python.exe -m unittest discover -s Duray/tests -p test_attendance.py -v
```

실제 브라우저 모의 화면 테스트는 `DOORAY_TEST_BROWSER`에 설치된 Chromium 실행 파일 경로를 지정하고 `test_browser.py`를 실행합니다. 네트워크 요청은 테스트 HTML로 대체하므로 실제 계정에 접근하지 않습니다.

```powershell
.\Duray\build_exe.ps1 -Clean -Python .\.venv\Scripts\python.exe -DistPath .\release
.\Duray\make_package.ps1 -Python .\.venv\Scripts\python.exe -Out .\release
```

`-Clean` 빌드는 기본 템플릿만 포함하여 계정, 개인 일정, 회사별 선택자를 배포 파일에 넣지 않습니다. `make_package.ps1`은 지정 폴더 전체를 삭제하지 않고 배포 파일만 갱신합니다. 시간 선택·캘린더 위젯은 `ui_widgets.py`에 있습니다.

소스 실행용 예약 등록은 `Duray/install_task.ps1 -Python <python.exe>`입니다. CLI는 `dooray_gui.py --watch`, `--run`, `--run --checkout`, `--install-browser`를 지원합니다. `dooray_checkin.py --action checkout --dry-run`으로 퇴근 인식만 확인할 수도 있습니다.

개발·테스트 격리를 위해 `DOORAY_DATA_DIR`, `DOORAY_CONFIG_PATH` 환경변수를 지원합니다. 실제 데이터는 기본적으로 `%LOCALAPPDATA%\DoorayCheckin`에, 소스 설정은 `Duray/config.json`에 저장됩니다.
