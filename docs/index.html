Python을 따로 설치할 필요 없이 Windows 배포 ZIP을 사용합니다. 최초 설치에는 Chromium 다운로드를 위한 인터넷 연결이 필요합니다.

● 자동 예약 실행 중

설정을 저장한 뒤 이 표시를 확인하세요.
시간 입력과 설정 저장만으로 예약이 켜지지는 않습니다.

  1. Windows ZIP 다운로드

    최신 릴리스에서 이름이 -windows.zip으로 끝나는 파일을 받습니다.

  2. 압축을 풀고 설치.bat 실행

    ZIP 안에서 바로 실행하지 말고 폴더에 먼저 압축을 해제합니다.

  3. 계정 저장 및 연결 확인

    ‘연결 · 설정’에서 회사 주소와 로그인 정보를 입력하고 ‘저장하고 연결 확인’을 누릅니다.

  4. 시간 설정 후 자동 예약 시작

    ‘시간 · 예약’에서 출퇴근을 설정하고 ‘저장하고 자동 예약 시작’을 누릅니다.

연결·예약 문제 해결 →
앱 창을 닫아도 예약이 실행되나요?

자동 예약을 켜 둔 상태라면 Windows의 예약 감시가 계속 실행됩니다. PC가 켜져 있고 Windows에 로그인되어 있어야 합니다. 전원 OFF나 절전 상태에서는 정상 실행을 기대할 수 없습니다.

예약 시각과 실제 출퇴근 기록이 왜 다른가요?

예약 시각은 처리를 시작하는 시각입니다. 이후 브라우저 실행과 로그인, 버튼 클릭 및 기록 확인이 이루어져 실제 두레이 기록은 몇 초 이상 늦어질 수 있습니다. 특정 초의 기록을 보장하지는 않습니다.

연차·반차가 자동 예약에도 적용되나요?

달력에 근태를 표시하는 것과 자동 예약에 반영하는 것은 별도입니다. ‘두레이 근태를 자동 예약에도 반영’을 체크하고 저장하면 휴가일 제외와 설정한 반차 퇴근 시각이 적용됩니다. 날짜별 수동 설정이 우선합니다.

업데이트할 때 다시 설정해야 하나요?

앱의 ‘연결 · 설정 → 업데이트 확인 → 다운로드 및 설치’를 사용하세요. 기존 계정·시간·달력·예약 ON/OFF를 유지하며 설치 시 이전 파일과 설정을 백업합니다. 비밀번호는 Windows 자격 증명 관리자에 저장됩니다.
